1. Executive Summary
The PIO Fund Serbia requires a comprehensive IT Help Desk system to support approximately 1,000 users across multiple branches. This system will implement a three-tier support structure (L1, L2, L3) aligned with ITSM best practices, featuring AI-powered automation, self-service capabilities, and a centralized knowledge base.
The system will be implemented to support the CORE 1 application launch scheduled for July 3, 2025, with demonstration capabilities required by May 13-16, 2025 for the training seminar.
Key Deliverables:

Multi-tier ticketing system with automated routing
Self-service portal with AI chatbot
Knowledge base with AI-powered suggestions
SLA management and tracking
Comprehensive reporting and analytics
Integration with external vendor ticketing systems


2. Project Overview
2.1 Project Context
The Republic Fund for Pension and Disability Insurance (PIO Fund) is implementing a new CORE 1 system for managing beneficiary records (CCAM). To ensure successful adoption and ongoing support, a robust Help Desk system is required.
2.2 Current State
Currently, IT support is fragmented across branches with no centralized ticketing or knowledge management system. This leads to:

Inconsistent problem resolution
No visibility into support metrics
Knowledge silos within individual branches
Inability to track SLA compliance

2.3 Future State Vision
A unified, AI-powered ITSM platform that:

Centralizes all IT support requests
Enables self-service for common issues
Provides real-time visibility into support operations
Automates routine tasks and escalations
Builds institutional knowledge through AI analysis
