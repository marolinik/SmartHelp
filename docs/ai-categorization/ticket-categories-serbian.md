## 1. ДЕФИНИСАНЕ КАТЕГОРИЈЕ ТИКЕТА

### 1.1 Примарне Категорије

#### ХАРДВЕР (HARDWARE)
- **Српски назив**: "Хардвер", "Хардверски проблеми"
- **Опис**: Проблеми са физичким компонентама компјутера, штампача, скенера и друге опреме
- **Кључне речи**: рачунар, штампач, скенер, миш, тастатура, монитор, диск, меморија
- **Примери**:
  - "Штампач не ради"
  - "Рачунар се не укључује"
  - "Монитор не приказује слику"
  - "Тастатура не ради"

#### СОФТВЕР (SOFTWARE)
- **Српски назив**: "Софтвер", "Софтверски проблеми"
- **Опис**: Проблеми са апликацијама, програмима и софтверским грешкама
- **Кључне речи**: програм, апликација, инсталација, грешка, софтвер, верзија
- **Примери**:
  - "Програм се укида"
  - "Не могу да инсталирам софтвер"
  - "Апликација не одговара"
  - "Грешка у програму"

#### МРЕЖА И ИНТЕРНЕТ (NETWORK)
- **Српски назив**: "Мрежа", "Интернет", "Мрежни проблеми"
- **Опис**: Проблеми са мрежном кonekcијом, интернетом и мрежним ресурсима
- **Кључне речи**: интернет, мрежа, веза, конекција, WiFi, LAN, RJ45
- **Примери**:
  - "Нема интернета"
  - "Спора интернет веза"
  - "Не могу да се повежем на мрежу"
  - "WiFi не ради"

#### НАЛОГ И ПРИСТУП (ACCOUNT_ACCESS)
- **Српски назив**: "Налог", "Приступ", "Корисничко име"
- **Опис**: Проблеми са корисничким налозима, правима приступа и аутентификацијом
- **Кључне речи**: налог, корисничко име, права, приступ, блокиран, активација
- **Примери**:
  - "Блокиран ми је налог"
  - "Немам приступ систему"
  - "Нужна су ми већа права"
  - "Налог се не активира"

#### ЛОЗИНКЕ (PASSWORDS)
- **Српски назив**: "Лозинка", "Шифра", "Resetovanje лозинке"
- **Опис**: Проблеми са лозинкама, резетовање, промена или заборављене лозинке
- **Кључне речи**: лозинка, шифра, заборавио, промена, ресет, resetovanje
- **Примери**:
  - "Заборавио сам лозинку"
  - "Требам да променим лозинку"
  - "Лозинка ми је истекла"
  - "Не прихвата лозинку"

#### EMAIL (EMAIL)
- **Српски назив**: "Имејл", "Електронска пошта", "E-mail"
- **Опис**: Проблеми са електронском поштом, слањем, примањем или конфигурацијом
- **Кључне речи**: имејл, e-mail, пошта, слање, примање, outlook, thunderbird
- **Примери**:
  - "Не могу да пошаљем имејл"
  - "Не стижу ми имејлови"
  - "Outlook не ради"
  - "Проблем са електронском поштом"

#### СИСТЕМСКЕ ГРЕШКЕ (SYSTEM_ERRORS)
- **Српски назив**: "Системска грешка", "Грешка система", "System error"
- **Опис**: Грешке оперативног система, Blue Screen, крахови и нестабилност
- **Кључне речи**: грешка, error, крах, plavi екран, crash, систем, Windows
- **Примери**:
  - "Плави екран грешке"
  - "Систем се рестартује"
  - "Критична грешка"
  - "Windows не ради"

#### ОБУКА И ПОДРШКА (TRAINING_SUPPORT)
- **Српски назив**: "Обука", "Како да", "Упутство", "Подршка"
- **Опис**: Захтеви за обуку, упутства за коришћење или помоћ око процедура
- **Кључне речи**: како, упутство, обука, процедура, помоћ, научити
- **Примери**:
  - "Како да користим програм"
  - "Треба ми упутство"
  - "Обука за нови софтвер"
  - "Помоћ око процедуре"

#### НОВИ ЗАХТЕВИ (NEW_REQUESTS)
- **Српски назив**: "Нови захтев", "Инсталација", "Постављање"
- **Опис**: Захтеви за нови софтвер, хардвер, налоге или услуге
- **Кључне речи**: нови, захтев, инсталација, постављање, требам, потребно
- **Примери**:
  - "Требам нови софтвер"
  - "Захтев за инсталацију"
  - "Потребан ми је нови налог"
  - "Постављање новог штампача"

#### ОСТАЛО (OTHER)
- **Српски назив**: "Остало", "Разно", "Друго"
- **Опис**: Проблеми који не спадају у друге категорије
- **Кључне речи**: остало, разно, друго, специјално
- **Примери**:
  - "Неки други проблем"
  - "Специфичан захтев"
  - "Не знам у коју категорију спада"

## 2. СРПСКА IT ТЕРМИНОЛОГИЈА

### 2.1 Основни IT Термини

#### Хардвер (Hardware)
```
Српски → Енглески → Опис
---------------------------------------
рачунар → computer → desktop/laptop компјутер
штампач → printer → device за штампање
скенер → scanner → device за скенирање
миш → mouse → pointing device
тастатура → keyboard → typing device
монитор → monitor/display → екран
диск → disk/drive → storage device
меморија → memory/RAM → радна меморија
процесор → processor/CPU → централна јединица
матична → motherboard → главна плоча
```

#### Софтвер (Software)
```
Српски → Енглески → Опис
---------------------------------------
програм → program/application → софтверска апликација
апликација → application → програм
софтвер → software → програмски код
систем → system → оперативни систем
Windows → Windows → Microsoft OS
Office → Office → Microsoft пакет
инсталација → installation → постављање софтвера
ажурирање → update → обновляване верзије
верзија → version → издање софтвера
лиценца → license → дозвола за коришћење
```

#### Мрежа (Network)
```
Српски → Енглески → Опис
---------------------------------------
интернет → internet → глобална мрежа
мрежа → network → локална/глобална веза
веза → connection → мрежна кonekcија
WiFi → WiFi → бежична мрежа
LAN → LAN → локална мрежа
каблови → cables → мрежни каблови
рутер → router → мрежни уређај
switch → switch → мрежни разделник
firewall → firewall → заштитни зид
IP адреса → IP address → мрежна адреса
```

#### Безбедност (Security)
```
Српски → Енглески → Опис
---------------------------------------
лозинка → password → приступна шифра
шифра → password/code → тајни код
налог → account → кориснички профил
права → permissions → приступна права
блокиран → blocked → забрањен приступ
вирус → virus → злонамеран софтвер
antivirus → antivirus → антивирусни програм
backup → backup → резервна копија
безбедност → security → заштита система
енкрипција → encryption → шифровање података
```

// Пример архитектуре модела

### 5.2 Метрике Оцењивања

#### Основне Метрике
- **Accuracy**: Укупна тачност модела
- **Precision**: Прецизност по категоријама
- **Recall**: Покривеност по категоријама
- **F1-Score**: Хармонијска средина precision и recall

#### Српски Специфичне Метрике
- **Ћирилица/Латиница Accuracy**: Тачност за различита писма
- **Дијалекат Robustness**: Отпорност на регионалне варијације
- **Терминологија Coverage**: Покривеност IT терминологије
